X推文半自动运营插件 · 设置

插件只生成文案，不自动发帖、不点赞、不关注。复制文案后请自己到 X 里手动发送。

国内用户推荐智谱 GLM 或硅基流动，不用代理、国内直接访问。API Key 只保存在你自己的浏览器里，不会上传到任何服务器。

智谱 GLM

免费领取：智谱开放平台 open.bigmodel.cn，注册登录后在控制台创建 API Key。GLM-4-Flash 永久免费，每天 100 万 token。
默认 glm-4-flash（免费）。想用更新的免费版可改成 glm-4.7-flash。

硅基流动

免费领取：硅基流动 API Key 管理，注册登录后创建 Key。新用户送 2000 万 token，Qwen3-8B 等模型永久免费。
默认 Qwen/Qwen3-8B（免费）。其他免费模型如 deepseek-ai/DeepSeek-R1-Distill-Qwen-7B、THUDM/GLM-4-9B-0414，免费列表以官网价格页为准。

Gemini

免费领取：Google AI Studio，用你的 Google 账号登录后点“Create API key”。免费档每天 250 次。
默认 gemini-3.8-flash（免费、快速）。

Claude

在 Anthropic Console 创建。注意：Claude API 是按量付费的，新账号一般有 $5 免费额度，用完需充值。
默认 claude-haiku-4-5（便宜快速）；想质量更好可改成 claude-sonnet-4-5。
留空则 AI 自由发挥，不限定方向；想往某个方向写就填上，比如：命理、玄学、星座、塔罗。
一次生成多条时，每条用一种不同风格（比如默认 3 条就是自然口语、专业干货、幽默各一条），从这里选的风格开始轮换；只生成 1 条时就用这里选的风格。热门文案的风格在热门页里单独选。
