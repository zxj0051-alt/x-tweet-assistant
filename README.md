# X推文半自动运营插件

在 X（Twitter）上手动回帖很累，全自动 AI 又容易被封。这个插件只帮你做一半：**点开推文自动抓内容、AI 生成回复草稿和发帖文案，你复制、你发帖。** 不自动发帖、不点赞、不关注、不转发，账号安全掌握在你自己手里。

**不用后端，不用部署。** 插件直接调你选的 AI 提供商，你在设置页填自己的 API Key 就能用，不用搭服务器、不用配 Worker。

## 功能

### 回复助手
- 在 X 上点开任意一条推文，右侧面板自动抓取推文内容（作者、句柄、正文），AI 生成 3 条回复草稿。
- 默认 3 条草稿风格各不相同（自然口语、专业干货、幽默各一条），每条打上风格标签，方便挑；不满意可以单条重新生成（保持原来那条的风格）。
- 支持三种风格：自然口语 / 专业干货 / 幽默。

### 热门文案
- 一键抓取 X 右侧热搜 + 当前时间线里互动最高的推文，展示成可点的热词。
- 可以自己添加热词（保存在浏览器里，下次打开还在），点一下选中 / 取消，选好热词和内容风格后再点“生成文案”。
- 文案带钩子（开头一句抓人），直接复制去发帖。

### 其他
- 领域描述可选：留空 AI 就自由发挥，不限定方向；填上（比如：命理、科技、美食）就往那个方向靠。
- 每次生成条数可调（1–5 条）。
- 防乱码：AI 偶尔返回格式错乱的 JSON，插件会把草稿正文提取出来再显示，不会直接甩一串 JSON 给你。
- 面板和设置页底部显示版本号和联系作者，版本号随 manifest 自动同步。

## 支持的 AI 模型

插件不绑死任何一家 AI，提供商可以在设置页随时切换。API Key 只保存在你自己的浏览器里，不会上传到任何服务器。

| 提供商 | 默认模型 | 费用 | 适合人群 |
|---|---|---|---|
| 智谱 GLM（默认） | glm-4-flash | 永久免费，每天 100 万 token | 国内用户首选，国内直连不用代理 |
| 硅基流动 | Qwen/Qwen3-8B | Qwen3-8B 等模型永久免费；新用户送 2000 万 token | 国内用户，喜欢换模型玩 |
| Gemini | gemini-3.8-flash | 免费，每天 250 次 | 有 Google 账号、能访问 Google 的用户 |
| Claude | claude-haiku-4-5 | 按量付费，新账号一般有 $5 免费额度 | 追求文案质量，愿意付费的用户 |

### Key 领取地址
- 智谱 GLM：https://open.bigmodel.cn/ ，注册登录后在控制台创建 API Key
- 硅基流动：https://cloud.siliconflow.cn/me/account/ak ，注册登录后创建 Key
- Gemini：https://aistudio.google.com/apikey ，用 Google 账号登录后点“Create API key”
- Claude：https://console.anthropic.com/settings/keys

## 安装

Chrome / Edge 均可（Manifest V3，未上架 Chrome 应用商店，需手动加载）：

1. 下载本仓库（Code → Download ZIP），解压到一个文件夹。
2. 打开 `chrome://extensions`，打开右上角“开发者模式”。
3. 点“加载已解压的扩展程序”，选择解压后的文件夹。
4. 看到插件图标即安装完成。

## 配置

1. 点插件图标旁的“设置”（或在 X 页面右侧面板点底部的“设置”）。
2. 选择 AI 提供商，填入对应的 API Key，点“保存”。
3. （可选）填“领域描述”和“回复风格”，调整每次生成条数。

国内用户推荐直接用智谱 GLM：去 open.bigmodel.cn 注册领个免费 Key 填进去就能用，不用代理。

## 使用

- **回帖子**：在 X 上点开任意推文，右侧自动弹出助手面板并生成回复草稿，挑一条喜欢的点“复制”，粘贴到 X 回复框里自己发。
- **发新帖**：点面板里的“热门文案”标签，点“抓取热门”，AI 会根据当前热搜和高互动推文写几条发帖文案，复制喜欢的去发。
- 生成失败时点“重新生成”一般就好；换个提供商也可以。

## 隐私与安全

- 插件只读 X 页面的公开推文内容（你点开的那条、热搜、高互动推文），不读私信、不读账号信息。
- API Key 存在浏览器本地（chrome.storage.sync），只在调用你选的 AI 接口时使用。
- 插件不自动发帖、不点赞、不关注、不转发。所有发布动作都由你手动完成，这是为了降低封号风险——请勿用任何工具全自动发帖。

## 常见问题

**Q：提示“请求失败，请检查 Key 与网络”怎么办？**
A：先确认 Key 填对了（复制时别多空格）、模型名没改错；再确认网络能访问对应接口（Gemini、Claude 需要能访问 Google / Anthropic，国内用户建议用智谱 GLM 或硅基流动）。

**Q：生成的文案是乱码 / 一串 JSON 怎么办？**
A：v1.3 已修：解析器会提取草稿正文，面板显示前还会再清洗一次，正常情况下不会再出现。如果还遇到，把面板截图发 issue。

**Q：能全自动发帖吗？**
A：不能，也不建议。X 对自动化发帖查得严，全自动容易封号。这个插件的定位就是“半自动”：AI 写，你发。

**Q：换了新版本，旧的设置还在吗？**
A：在。设置存在浏览器本地，升级插件不会丢。换电脑的话需要重新填 Key。

## 开发

本项目是纯前端 Chrome 扩展（Manifest V3），无构建步骤，直接改代码、重新加载就能测。

```
manifest.json    扩展配置（名称、权限、版本）
background.js    Service Worker：按提供商调 AI 接口、解析草稿
content.js       内容脚本：抓推文、抓热搜、渲染右侧面板
options.html     设置页
options.js       设置页逻辑
icons/           图标
```
